This folder is a convenience wrapper around the parent `pcairplay` project. It
does not contain the AirPlay protocol implementation.

- **UxPlay**: the AirPlay receiver used by this project. UxPlay is maintained
  by [FDH2](https://github.com/FDH2/UxPlay) and is licensed under GPL-3.0.
- **uxplay-windows**: the Windows distribution used by the parent setup script.
  It is maintained by [leapbtw](https://github.com/leapbtw/uxplay-windows).
- **Bonjour**: Apple's mDNS service, installed separately on Windows.
